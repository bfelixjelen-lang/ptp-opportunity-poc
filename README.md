# Pathways to Purpose Opportunity Guide POC

This is a proof-of-concept Streamlit app for exploring Pathways to Purpose / Global Impact Center opportunity records.

This version uses public/demo data only. It does not include student records, private partner contacts, risk notes, budgets, internal logistics, or protected university information.

## Files

- `app.py` - Streamlit application
- `ptp_opportunities.csv` - demo opportunity records
- `requirements.txt` - Python dependencies

## Purpose

The app demonstrates a student-facing opportunity discovery interface with filters, browse cards, and a basic "Match Me" recommendation workflow.
